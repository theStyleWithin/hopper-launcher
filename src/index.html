Before you install

At your own risk

Install anything from gamehopper at your own risk. If you are unsure, try it in a virtual machine first.

Found a problem?

Post it in the repository of the app that is giving you trouble. Settings has a Report issue button for each app.

Tested on Linux only, for now

The developer uses Linux and has tested only the Linux versions. Windows and Android versions are untested and may have bugs. Windows users are wanted, and your reports help.
